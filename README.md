# Сложно сосредоточиться

Адаптивная страница о концентрации внимания. Учебный проект Яндекс Практикума.

[Репозиторий проекта](https://github.com/Saakoz14/slozhno-sosredotochitsya)

## Превью сайта

![Сложно сосредоточиться — тёмная тема](./preview.png)

## Возможности

- Светлая, тёмная и автоматическая темы.
- Адаптивная вёрстка для телефона, планшета и компьютера.
- Галерея изображений и гибкая типографика.

## Технологии

HTML5, CSS3, Grid Layout, Flexbox, CSS-переменные и медиазапросы. JavaScript для переключения темы, локальный шрифт IBM Plex Mono.
